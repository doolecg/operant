# Operant 2 2.0.0

The first release of Operant 2: run crews of coding agents from one dashboard.

### New

- **Crews, squads and operators.** A crew is a team working in one project folder. Squads group its operators, and each operator is a Claude Code, Codex or shell session with a stable address such as `lead@shop`.
- **Live dashboard.** See every operator's status, model, context use and current task, start and stop them, and open any operator's terminal in a side panel.
- **Activity, tasks and cost.** A live activity feed, a task board you can move tasks around on, and per-operator spend over the last 24 hours, estimated from Claude Code transcripts.
- **CodeGraph indexing.** Index a crew's project with CodeGraph from the dashboard; operators are told to use it before searching files.
- **The operant skill.** Every Claude Code operator starts with Operant's skill loaded, without anything being written into your project.
- **Settings.** Daily budget, default models, the shell operators run in, update options, and rebindable keyboard shortcuts, all applied as you change them.
- **Automatic updates.** Operant 2 checks GitHub for new versions, downloads them in the background, and installs on restart or when you quit.
- **Windows, macOS and Linux** installers (MSI, DMG, AppImage and deb).
